# Tree Assessment Schedule

離線記錄場地樹木評估表（Batch、Tree No.、Species Name、H、S、DBH、Remarks、Recommendation），並匯出 Excel。資料只在你的瀏覽器處理，不會上載到伺服器。

開啟：[https://davychan188.github.io/field-tree-schedule/](https://davychan188.github.io/field-tree-schedule/?v=15)

## iPad mini + Apple Pencil 建議用法

1. 用 **Safari** 打開上面的連結（不要用 Chrome 內的 insite 瀏覽器）。
2. 點分享按鈕，選 **加入主畫面**。之後當一個 App 打開，第一次載入後，現場無網絡都可以繼續用。
3. 在「設定 > Apple Pencil」開啟 **Scribble（隨手寫）**，品種欄就可以用 Pencil 直接手寫。
4. 畫面以 Excel 列表顯示，每頁 20 項，可翻頁繼續填。
5. 填完記得 **匯出 Excel**，或「下載 HTML 備份」。主畫面圖示嘅暫存較穩，但清 App／換機就會冇，備份最穩陣。改錯可以撳工具列嘅 **上一步**（最多 50 步），**重做** 可以再改返去。

填表方式：

- **Batch**、**H / S / DBH**：撳欄位會喺下面彈出九宮格數字鍵盤（可用 Pencil 點）。Batch 同 Tree No. 係整數；H／S／DBH 可以有小數。
- **Tree No.**：號碼請自己用鍵盤輸入；或喺上方揀 **T / AT / TG**，按上一頁／已有編號嘅順序，一次過填滿本頁空白嘅 20 個號碼（已輸入嘅唔會改）。單棵仍可喺鍵盤改。⭐ 可以加喺前綴前面（例如 ⭐T12）。
- **Species Name**：撳欄位會喺畫面上方開一個大輸入欄，可以打字或用 Pencil 手寫中文／學名，即時搜尋香港 TMO 清單。選中後，表內會存學名，並顯示中文提示。清單冇嘅名都可以照你寫嘅字存檔。

欄位：H＝高度（m）、S＝冠幅（m）、DBH＝胸徑（mm）。匯出嘅 Excel 格式同 Tree Assessment Schedule 範本一致。
