# Tree Assessment Schedule

離線記錄場地樹木評估表（Tree No.、Species Name、H、S、DBH、Condition、Remarks、Recommendation），並匯出 Excel。資料只在你的瀏覽器處理，不會上載到伺服器。

開啟：[https://davychan188.github.io/field-tree-schedule/](https://davychan188.github.io/field-tree-schedule/?v=64)

## iPad mini + Apple Pencil 建議用法

1. 用 **Safari** 打開上面的連結（不要用 Chrome 內的 insite 瀏覽器）。
2. 點分享按鈕，選 **加入主畫面**。之後當一個 App 打開，第一次載入後，現場無網絡都可以繼續用。
3. 在「設定 > Apple Pencil」開啟 **Scribble（隨手寫）**，品種欄就可以用 Pencil 直接手寫。
4. 畫面以 Excel 列表顯示，每頁 10 項，可翻頁繼續填。
5. 填完記得 **匯出 Excel**，或「下載 HTML 備份」。主畫面圖示嘅暫存較穩，但清 App／換機就會冇，備份最穩陣。改錯可以撳工具列嘅 **上一步**（最多 50 步），**重做** 可以再改返去。**清除全部** 要先確認先會刪除資料，之後亦可用上一步復原。

填表方式：

- **H / S / DBH**：撳欄位會喺下面彈出九宮格數字鍵盤（可用 Pencil 點）。H／S／DBH 可以有小數。
- **Condition**：撳欄位或「選」會喺畫面中間彈出對話框（同 Remarks 一樣），揀 Health、Structure、Form，每項可選 N（Normal）、F（Fair）、P（Poor）、VP（Very poor）。表內同 Excel 以 `N/F/VP` 顯示。
- **Tree No.**：號碼請自己用鍵盤輸入；或喺上方揀 **T / AT / TG**，一次過填本頁空白號碼（已輸入嘅唔會改）。若已先選中一格有編號嘅行（例如 569 或 TG-T569），只會由呢行下面開始填，第一個係選中編號加 1（570），上面空白唔會填。冇選中行就按上一頁／已有編號嘅順序填滿本頁空白。TG 會寫成 **TG-T** 加數字（例如 TG-T12、⭐TG-T12）；位數跟已有 T／TG 編號一樣，唔會強制補夠 4 位。單棵仍可喺鍵盤改。⭐ 可以加喺前綴前面（例如 ⭐T12）。
- **Remarks**：匯入或開啟舊記錄時，原有備註會以**紅色**顯示為舊資料，新輸入嘅備註係**黑色**。上面欄有「全部保留」（將舊資料轉成黑色新資料）同「全部刪除」（刪除前會確認，可用上一步復原）；每行唔會再顯示保留／刪除掣。工具列可隨時轉 **A**、**B** 或 **C**（會記住）。A：上面得 Severely、Large（加喺 defect 前面）同 Dead（Dead tree）。Crown 得 Top（Topped）、SF、Dieback、ASY、Reduced、PEST。Branch／Trunk／Trunk base 可揀 Wound、Cavity、EDW（Exposed dead wood on …）、Dead、ABC、Broken，會組成例如 Exposed dead wood on branch；Trunk base 冇 B 同 Dead，另有 RPM、Uprooted。Trunk 另有 Leaning、Bending、COT、IB（Included bark）；各組快捷按英文名稱排序。B：用英文簡寫清單（ABCB、ABCT、ASY、BB、C、COT、DB、DT、L、OXB、RPM、SF、WLT、WOB、WOT），不分 Crown／Branch／Trunk。C：上面同樣有 Severely、Large 同 Dead（Dead tree）。Location 有 Location（再揀 On slope／drainage／shore）、In conflict（再揀 Hoarding／Building／Fencing／Wall）、RR（再揀 Hoarding／Debris）、proximity（再揀 Hoarding／Building／Fencing／Wall）。快捷分 Health、Structure、Form 三欄。Health：Dieback、Sparse foliage、Wilting。Structure：Dead（再揀 Branch／Trunk，不是 Dead tree）、Broken（再揀 Branch／Trunk）、Cavity（再揀 Branch／Trunk／Trunk base）、Decaying（再揀 Branch／Trunk／Trunk base）、Trunk（再揀 COT／Poor taper／Multiple trunks）、Root（再揀 Uprooted／Girdling root／RPM）。Form：ASY、Leaning、OXB、Bending、Suppressed（Suppressed by adjacent trees）。按鈕只顯示簡稱（In conflict、Sparse foliage、Leaning 顯示全寫），存檔同匯出用正式英文名稱。三種模式底下嘅搜尋欄仍可搵其他備註。
- **Species**：撳欄位會喺畫面中間開一個手寫／搜尋框，可以打字或用 Pencil 手寫中文／學名，即時搜尋香港 TMO 清單。選中後，表內只顯示中文名（匯出 Excel 仍存學名）。清單冇嘅名都可以照你寫嘅字存檔。

欄位：H＝高度（m）、S＝冠幅（m）、DBH＝胸徑（mm）。匯出嘅 Excel 格式同 Tree Assessment Schedule 範本一致。
