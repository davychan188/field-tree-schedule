# Tree Assessment Schedule

離線記錄場地樹木評估表（Batch、Tree No.、Species Name、H、S、DBH、Defect），並匯出 Excel。資料只在你的瀏覽器處理，不會上載到伺服器。

開啟：[https://davychan188.github.io/field-tree-schedule/](https://davychan188.github.io/field-tree-schedule/)

## iPad mini + Apple Pencil 建議用法

1. 用 **Safari** 打開上面的連結（不要用 Chrome 內的 insite 瀏覽器）。
2. 點分享按鈕，選 **加入主畫面**。之後當一個 App 打開，第一次載入後，現場無網絡都可以繼續用。
3. 在「設定 > Apple Pencil」開啟 **Scribble（隨手寫）**，即可用 Pencil 在欄位直接手寫，系統會轉成文字。
4. **直向**用上方「快速加入」逐棵填；**橫向**方便一次睇晒成個表同改已輸入嘅列。
5. 填完記得 **匯出 Excel**，或「下載 HTML 備份」。主畫面圖示嘅暫存較穩，但清 App／換機就會冇，備份最穩陣。

畫面以 Excel 列表顯示，每頁 10 項，可翻頁繼續填。撳 H／S／DBH 會彈出九宮格數字鍵盤（可用 Apple Pencil 點）。

欄位：H＝高度（m）、S＝冠幅（m）、DBH＝胸徑（mm）。匯出嘅 Excel 格式同 Tree Assessment Schedule 範本一致。
